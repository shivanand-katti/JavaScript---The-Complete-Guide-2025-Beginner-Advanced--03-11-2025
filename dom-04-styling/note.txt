** Adding Elements vis HTML in code:

add the elements using innerHTML
const container = document.getElementById('container');
container.innerHTML = '<div class="new-element">This is a new element</div>';
or create elements using createElement and appendChild
const newElement = document.createElement('div');
newElement.className = 'new-element';
newElement.textContent = 'This is a new element';
container.appendChild(newElement);

** Styling Elements via JavaScript:
// Using the style property
const element = document.getElementById('my-element');
element.style.backgroundColor = 'lightblue';
element.style.fontSize = '20px';
// Adding a CSS class
element.classList.add('highlighted');
// Removing a CSS class
element.classList.remove('highlighted');
// Toggling a CSS class
element.classList.toggle('highlighted');
// Changing multiple styles at once using cssText
element.style.cssText = 'color: red; margin: 10px;';
// Using setProperty for more control
element.style.setProperty('border', '2px solid black');
element.style.setProperty('padding', '5px');
// Removing a specific style
element.style.removeProperty('font-size');
// Clearing all inline styles
element.style.cssText = '';

** Note on Specificity and !important
When using JavaScript to style elements, inline styles added via the style property 
will generally have higher specificity than styles defined in external stylesheets. 
However, styles marked with !important in CSS will override inline styles unless the 
inline style also uses !important.

** Best Practices
- Prefer adding/removing CSS classes for styling changes to maintain separation of concerns.
- Use inline styles sparingly for dynamic styling that cannot be achieved through classes.
- Always consider performance implications when manipulating the DOM, especially in loops.
